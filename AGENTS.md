# Agentstration Newsletter contributor rules

- Every edition corresponds to a published Agentstration release.
- `gbaudrit/agentstration` and the published tag are the product source of truth.
- English and French are required for every edition.
- Both languages must cover the same product changes.
- Never present a feature that is absent from the published tag.
- Product screenshots must come from the tagged version.
- Never commit sensitive data, credentials, personal identifiers, or local paths.
- Never publish automatically to LinkedIn.
- Private prompts and drafts stay in `agentstration-communication`.
- This public repository contains only publication-ready material.
- Keep the design aligned with `agentstration-website`.
- Keep theme and language-switcher behavior aligned with the main website.
- Every edition must pass the build and checks before publication.
